## 一、世界观

### 1.1 魔法岛（Island）

一座被大海环绕的神秘小岛，外面的人并不知道它的存在。岛上有一层**防护罩**保护着，平时看不见，只有在特殊时刻（台风、星光之夜）才会显现。

岛上的居民过着普通的生活，他们不知道魔法学院的城堡其实是一座真正的魔法学校——在他们眼里，那只是一栋漂亮的老房子。

**岛的地理分区（手绘地图锚点）**

| 分区 | 位置 | 代表角色 |
|---|---|---|
| **魔法城堡** | 中央山坡 | 晶晶、亮亮、老师们、同学 |
| **花园** | 城堡西侧 | 小昆虫、爱丽丝、小玫瑰 |
| **操场** | 城堡东侧 | 全员集合点；防光罩练习场 |
| **森林小路** | 城堡北侧 | 通向海边 |
| **海滩** | 岛的最北 | 塔利亚守护；小海洋的家 |
| **居民小镇** | 城堡外围 | 不知情的普通岛民（不知道城堡是魔法学院，以为只是一栋漂亮的老房子） |
| **海面** | 全岛环抱 | 塔利亚的领域 |

### 1.2 魔法学院（Academy）

建在魔法岛中央山坡上的古老城堡，**法式新哥特风格**：白墙蓝顶、尖塔、玫瑰花窗、彩色玻璃、金色雕花栏杆、白色大理石旋转楼梯。城堡里有水晶吊灯、飘浮的抱枕、说话的水晶球。

> **视觉锚点**：`assets/banners/城堡横版.jpg` / `城堡玩耍.jpg` / `城堡近景横版.jpg`

**班级划分**

- **初级班**：4–5 岁，学最基础的感知魔法（晶晶、亮亮在这里，亮亮比晶晶早入学一点点；v12：点点 3 岁入学，是学院史上最小的学生，初级班年龄下限就此下探）
- **中级班**：6–7 岁，学更复杂的元素魔法
- **高级班**：8–9 岁，学保护小岛的魔法

> 📌 学院规模小，实行**混龄同班**：初级/中级/高级是魔法课程的进度分级，不是分班依据——同班、同桌可以跨级（v4 设定）。

学院有魔法课、画画课、音乐课、甜点课……每一节课都很有趣。

### 1.3 国家守护者（Guardians）

四位守护者守护着魔法岛和防护罩的安全。他们平时很神秘，只有在小岛遇到危险时才会出现。

**视觉共性**：站姿是"单手叉腰 / 单手摊开魔法阵光"；身后有**半透明蛋壳形魔法阵光晕**；身穿长礼服 + 高跟鞋 + 王冠 + 守护杖。

| 姓名 | 守护元素 | 视觉特征 | 服装主色 |
|---|---|---|---|
| **奥利夏** | 阳光 | 粉紫渐变长卷发，王冠 | 粉紫渐变礼服，紫水晶杖 |
| **奥利安** | 星空 | 金色长马尾，红宝石杖 | 橙金长礼服 |
| **爱丽丝** | 花园 | 粉发双马尾，**粉色翅膀** | 粉白花瓣礼服，心形杖 |
| **塔利亚** | 海洋 | 浅蓝短发，蓝宝石杖 | 蓝白渐变礼服 |

> 奥利夏与奥利安名字呼应"夏夜星空"——奥利夏是白天的太阳守护者，奥利安是夜晚的星星守护者。

## 三、魔法体系（基础规则，不复杂）

### 3.1 入门魔法 · 感知

初级生最先学的是**感知魔法**——闭上眼睛，感受身边的魔法元素。

故事里晶晶第一次就感受到了一颗小光球；亮亮感受到了一朵棉花糖一样的小云。

### 3.2 魔法方向（每个小朋友各有所长）

| 方向 | 代表 |
|---|---|
| **光魔法** | 小光明、小太阳 |
| **月魔法** | 小月亮、小月光 |
| **自然魔法** | 小昆虫、爱丽丝 |
| **食物魔法** | 小甜点、小海绵阿姨 |
| **海洋魔法** | 小海洋、塔利亚 |
| **天气魔法** | 小天天 |

### 3.3 魔法道具

- **魔杖**：每人有专属形状（搅拌器、画笔、星星、月牙、心形……）
- **晴天娃娃**（小天天专属）：白圆脸、粉腮红、淡紫头发的小魔法娃娃，是小天天施展天气魔法的媒介。它白天乖巧地趴在主人肩上，夜晚会自己抬头收集月光。一旦找不到它——或者小天天找不到它——小天天就会因为"借不出天气"而情绪失控，**她的心情直接变成天气：开心出太阳、难过下雨、害羞出彩虹**（v2 设定，由小橘子口述"小天天找不到晴天娃娃后就一直哭，然后就一直下雨"确立）。

- **防护罩**：保护小岛；**防光罩**是户外练习时的临时遮阳罩（像大帐篷）
- **敲墙**：宿舍隔墙信号系统（见 4.2）

### 3.4 魔法三规

1. 魔法只能用来帮助别人，不能用来欺负人
2. 不可以在学院外面随便使用魔法
3. 每天要按时睡觉，睡好了魔法才会更强

### 4.5 小天天的天气魔法（v2 新增 · 由小橘子口述）

| 小天天的状态 | 天气 |
|---|---|

**晴天娃娃丢失协议**（学院默认反应）：
- 一旦发现下雨不止 + 小天天不在 → 大家先集合，再分组去城堡各角落找娃娃

> 📌 这个设定 v2 确立，第二集《晴天娃娃不见了》是它的首秀。后续可以发展：小天天学会更精细地控制天气（不下雨只阴天）、晴天娃娃自己会"离家出走"找乐子、其他人也想有能映射心情的魔法道具……

### 4.14 敖丙与"龙走到哪里，家就在哪里"（v15 新增 · 第十四集《两条小龙》确立）

### 4.15 小豆包与"准备了一百样，错了一样"（v17–v18 新增 · 第十五、十六集确立）

**小豆包档案**：6 岁中级生，**第一个比晶晶大的新同学**（此前新同学最大才 5 岁：茉茉 4、安雨 5、点点 3、莉莉阳阳 5、敖丙 5）——"这回来的，六岁，是一个大姐姐耶"。**她是小包子老师的女儿**（小橘子指定，第十五集确立）——学院里第一对"妈妈当老师、女儿当学生"的母女档；她想当一个普普通通的新同学，拜托妈妈先保密，老师答应了还装作刚知道。名字来源闭环：小包子老师的名字来自豆包 App，女儿就叫小豆包。淡紫色大尖帽、米白斗篷校服、黑色波波头，背着双肩书包还斜挎一个小包包，自带小心心魔杖（杖头黄黄的小心心，**第十六集揭晓心意魔法**）+ 碎花裙娃娃**包包**（**第十六集醒了**，第一个"等不及"的娃娃）。坐第一班魔法船到校，行李只有一个书包——"我自己都装好啦！"（行李箱第二天才寄到，小满保安："我就说嘛，怎么可能，只有一个书包！"）。桌子把她拼在小甜心旁边——"桌子会为好朋友挪出位置"的第六种变体：同龄拼桌（"桌子连谁一样大，都知道"）。

**"百宝袋"人设与小裂缝**：她的书包什么都有——卷笔刀（救晶晶的小橘子铅笔）、针线包（救安雨给小红豆缝的小裙子）、小别针（救阳阳的太阳徽章）。她提前把学校的样子都问清楚、**自己画了学院地图**——可是第一天去食堂就走反了：地图上，食堂和花园画反啦！"准备了一百样，错了一样。"（人设落地：像豆包 App 一样能干，但也会犯错——爸爸审定）

**题眼（礼物的流向）**：总是给大家准备东西的人，唯独没给自己准备什么——"小豆包的书包里，有所有人需要的东西。就是没有，大家送给她的东西。"第二天，全班一人往她书包里放了一样礼物：晶晶的手绘新地图（这一次食堂和花园都在对的地方）、茉茉的悄悄话小茉莉、安雨连夜缝的布小小豆包、敖丙的贝壳（放耳边能听见海）、莉莉的小黄花贴纸、阳阳的小太阳贴纸、点点的三颗光点、小甜心的饼干……"还有好多好多，我数都数不清。"她太开心，抱着书包冲到讲台前喊"妈妈！你看！"——保密当场公开（见破模板点①）。

**第十六集《包包等不及了》：回礼、心意魔法与包包苏醒**：小假期结束，晶晶亮亮回学院——"回归集"。小豆包给全班准备了回礼，还立下"这一次，全都我自己来"的清单，连蝴蝶结都要自己打。礼物发下来却错了三样：小甜心拿到点点那么大的蝴蝶结发夹，点点拿到草莓手帕；敖丙拿到写着"安雨收"的贝壳画龙书签，安雨拿到小海螺；晶晶拿到水晶贴纸，亮亮拿到云朵贴纸。三份都反啦！真相是包包这几天夜里偷偷帮小豆包包礼物，布手打的蝴蝶结歪歪的——"准备了一百样，错了一样。这一次……错了三样。"小豆包还特地给影子准备了一盏**小灯笼**：影子提起来，地上就有了一个圆圆的、小小的影子。她想"今晚重新包"，全班却一起喊"不要——"；她第一次什么都没准备，就收下了小甜心掰给她的半块饼干。就在这时，**心意魔法**揭晓——杖头黄黄的小心心"扑通扑通"跳了两下，然后亮了；小包子老师见证："真心换真心的时候，它就会亮。老师等它亮，等了好几天啦。"夜里，小豆包发现蝴蝶结的秘密，包包在她怀里**醒了**：这是第一个"等不及"的娃娃，没等主人停下来，想帮忙想着想着就自己醒了；醒后害羞地躲到帽子后面，把脸埋进小豆包怀里，又偷偷点了点头。她把自己包错的那张画反的旧地图折成一个**纸心心**，送给小豆包。小彩虹这几天夜里一直蹲在第九间门口听，早就知道包包在帮忙，替它保密——"醒来的娃娃，会找到醒来的娃娃。还会，替它们保密。"夜间娃娃网络扩到五个：**小彩虹 + 小树叶 + 小红豆 + 小绿豆 + 包包**，包包第一次参加夜巡。路过第五间（点点宿舍）时，里面"咚"地响了一声，像翻身；影子这次没有摇头，用力点了两下头——甜甜可能快醒了（第十一集挂账升级）。
